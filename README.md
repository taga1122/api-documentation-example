## 1. Описание бизнес-процесса

Интеграция с системой включает 3 основных этапа:
1. **Проверка статуса кода маркировки (Data Matrix)** на стороне Сервера.
2. **Валидация запроса** и сопоставление с товарной группой.
3. **Регистрация оборота товара** и получение подтверждения.

[Участник рынка] ---> (GET /check) ---> [Сервер Маркировки]|                                       ||<--- (200 OK / статус кода) -----------|

## 2. Спецификация REST API

### GET /api/v1/products/check
Возвращает информацию о текущем статусе и товарной группе кода маркировки.

* **Метод:** `GET`
* **Формат данных:** `JSON`
* **Авторизация:** Bearer Token в заголовке `Authorization`

#### Параметры запроса (Query Parameters)
| Параметр | Тип | Обязательный | Описание | Пример |
| :--- | :--- | :--- | :--- | :--- |
| `code` | string | Да | Уникальный код маркировки (GTIN + Serial) | `04601234567890abc` |
| `group_id` | integer | Нет | Идентификатор товарной группы | `40` |

#### Пример ответа (`200 OK`)
```json
{
  "status": "VALID",
  "product": {
    "gtin": "04601234567890",
    "group_name": "Упакованная вода",
    "owner_inn": "7701234567"
  }
}
